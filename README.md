1. MAIN PRODUCT CONCEPT

The application connects:

Taxpayers / users
↕
Accountants

The core idea is:

A user can scan their documents, invoices, purchase receipts, and tax-related paperwork, store them inside the application, and send them directly to an accountant they choose.

The user can also find nearby accountants through a real map using location services.

The app should automatically show the closest accountants first.

The user should be able to:

discover nearby accountants

see distance from current location

filter accountants by distance

view accountant profiles

choose an accountant

send documents to the chosen accountant

book an appointment

see available appointment times

select an available time

store invoices

scan invoices using the camera

upload documents from the phone

organize documents

send documents directly to their accountant

record purchases

review their purchase history

track accounting-related activity

view statistics and analytics

manage their account

The application should feel like a premium fintech / accounting / productivity product, NOT a generic CRUD application.
